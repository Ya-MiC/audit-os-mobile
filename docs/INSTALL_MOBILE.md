# 📱 手机版安装指南（3 分钟搞定）

> 适用：湛箴安卓采集端 v0.5。iOS 版在路线图（v1.0 后），当前安卓优先。

## 方式一：直接下载 APK 安装（推荐，2 步）

### 第 1 步：下载
手机浏览器打开（微信内请点右上角 ⋯ 选择「在浏览器打开」）：

```
https://github.com/Ya-MiC/audit-os-mobile/raw/main/dist/zhanzhen-v0.5.apk
```

或者到发布页下载（可看历史版本）：
```
https://github.com/Ya-MiC/audit-os-mobile/releases
```

### 第 2 步：安装
1. 下载完成后点开 APK → 系统提示「未知来源应用」→ 点**仍然安装/允许**
   （不同手机路径：小米「特殊权限」/ 华为「更多安全设置」/ 原生 Android「允许此来源」）
2. 打开「湛箴」图标 → 完成 ✅

> 为什么会提示未知来源：APK 没上应用商店（上架需要企业资质审核期）。
> 本 App 无任何敏感权限（无通讯录/定位/短信），代码全部开源可查。

## 首次使用两条路

| 模式 | 适合 | 怎么做 |
|---|---|---|
| **纯离线**（默认） | 还没买专业版/没服务器 | 打开即拍即存；「导出采集包」生成 json 传给电脑工作台 |
| **连接服务器**（专业版） | 有湛箴服务器账号 | 侧栏「设置」填 服务器地址 + API Key → 拍完点「☁️ 直接上传」 |

## 常见问题

| 问题 | 解决 |
|---|---|
| 微信里下载按钮没反应 | 点右上角 ⋯ → 浏览器打开 |
| 安装时提示「风险应用」 | 所有非商店 APK 的通用提示；本 App 开源可审计 |
| 拍照没反应 | 首次拍照跳转系统相机，拍完回 App 从相册选刚拍的图 |
| 上传失败 | 检查服务器地址含 http://、API Key 复制完整 |

## 数据安全承诺

- 纯离线模式：数据永不出手机
- 联服务器模式：只连你自己的湛箴服务器，HTTPS 加密传输
- 凭证照片所有权归你，队列里随时可删
